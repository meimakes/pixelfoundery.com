# Pixel Foundery

**Build anything with your kid + AI.**

A prompt generator for parents who want to introduce building things with AI to their kids. Pick your child's age, their interests, and a project type — get a ready-to-paste prompt that produces a working single-file HTML project in any AI chatbot.

## How It Works

1. **Age** — Select your kid's age (2–5)
2. **Interest** — What they're obsessed with (trucks, dinosaurs, space, animals, etc.)
3. **Project type** — Game, story, art tool, science experiment, math puzzle, or music maker
4. **Generate** — Get a tailored prompt, copy it, paste into Claude/ChatGPT/Gemini

The generated prompt is designed to produce a complete, working, single-file HTML project with:
- Touch-friendly controls for small hands
- Sound effects via Web Audio API (no external dependencies)
- Age-appropriate difficulty and pacing
- Visual feedback that keeps kids engaged

## Why

The cold start problem: parents want to build with their kids using AI, but don't know what to ask for. Pixel Foundery solves the blank-prompt-box problem by generating specific, tested, age-appropriate project prompts.

## Tech

- Single HTML file, no build step, no dependencies
- 25+ prompt templates across 6 categories
- Dark mode via `prefers-color-scheme`
- Mobile-first, fully responsive
